# Select, SelectField, Combobox, ComboboxField

Pick one value from a list that is too long to show in full. `SelectField` and
`ComboboxField` are ready-made fields; `Select` and `Combobox` are the styled
parts for building your own.

| Component       | Use it for                                                                           |
| --------------- | ------------------------------------------------------------------------------------ |
| `SelectField`   | One value from a short, fixed list. Pass `options`, `value`, `onChange`.             |
| `ComboboxField` | One value from a long list the user would rather search than scroll.                 |
| `Select.*`      | Multi-select, grouped options, options with icons or descriptions, a custom trigger. |
| `Combobox.*`    | A searchable list with groups or custom rows.                                        |

## When to use

- Five or more options, or options that would crowd the page if shown at once:
  a language, a model, a role.
- A setting in a dense list where each row ends in a choice: `SelectField`
  with `variant="ghost"`.
- A list the user searches by name, such as groups or members:
  `ComboboxField`.

## When not to use

- Two to four options that fit on screen → `Radio`, so the user sees every
  option without opening anything. A single on/off → `Switch` or `Checkbox`.
- Switching the view of the same content → `SegmentedControl` or `Tabs`.
- Running an action (Rename, Delete) → `Menu`. A select holds a value; a menu
  does something.
- Free text with suggestions the user may ignore → `Input`.

# Select, SelectField, Combobox, ComboboxField

다 펼쳐 보이기에는 긴 목록에서 값 하나를 고르게 합니다. `SelectField`와
`ComboboxField`는 바로 쓰는 필드이고, `Select`와 `Combobox`는 직접 조합할 때 쓰는
스타일이 입혀진 부품입니다.

| 컴포넌트        | 쓰는 곳                                                                  |
| --------------- | ------------------------------------------------------------------------ |
| `SelectField`   | 짧고 정해진 목록에서 값 하나. `options`, `value`, `onChange`를 넘깁니다. |
| `ComboboxField` | 스크롤보다 검색이 편한 긴 목록에서 값 하나.                              |
| `Select.*`      | 여러 개 선택, 묶은 항목, 아이콘이나 설명이 붙은 항목, 직접 만든 트리거.  |
| `Combobox.*`    | 묶음이나 직접 만든 행이 있는 검색 목록.                                  |

## 언제 쓰나요

- 선택지가 다섯 개 이상이거나, 한꺼번에 보이면 화면이 복잡해질 때: 언어, 모델, 역할.
- 행마다 끝에 선택이 하나씩 있는 촘촘한 설정 목록: `variant="ghost"`인 `SelectField`.
- 이름으로 찾는 목록(그룹, 멤버): `ComboboxField`.

## 언제 쓰지 않나요

- 화면에 다 들어가는 두세 개의 선택지는 `Radio`를 씁니다. 아무것도 열지 않고 모든
  선택지를 볼 수 있습니다. 켜고 끄는 값 하나는 `Switch`나 `Checkbox`를 씁니다.
- 같은 내용의 보기 방식을 바꿀 때는 `SegmentedControl`이나 `Tabs`를 씁니다.
- 이름 바꾸기, 삭제 같은 동작은 `Menu`를 씁니다. 셀렉트는 값을 담고, 메뉴는 일을
  합니다.
- 제안을 무시하고 자유롭게 써도 되는 텍스트는 `Input`을 씁니다.

| Variant             | Means                                                                                      | Use for                                                                                            |
| ------------------- | ------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| `outline` (default) | A bordered field, the same as `Input`. Width defaults to `full`.                           | Forms, modals, filters                                                                             |
| `ghost`             | No border until hover or focus; sized to its value. An invalid field keeps its red border. | The trailing choice in a settings row, where a column of bordered triggers would outweigh the card |

Other props: `size` (`xs`–`lg`, default `md`), `invalid`, `disabled`,
`readOnly`, `required`, `name`, `width`. `onChange` receives the value, or
`null` when the selection is cleared. `ComboboxField` adds `emptyText`; it has
no `variant` or `stagger`.

## Clearing the value

When "nothing chosen" is a valid value, let the user empty the field again: a
filter, or a form field that is not required. Do not offer it on a required
field.

`ComboboxField` already has the button. `SelectField` has none, so a
clearable select is composed from `Select.*`. With `Select.*` or
`Combobox.*`, put `ClearTrigger` in the indicator group, before the chevron:

```tsx
<Select.IndicatorGroup>
  <Select.ClearTrigger aria-label="조직 선택 지우기" />
  <Select.Indicator />
</Select.IndicatorGroup>
```

The part does the rest. It shows only while something is selected. It draws
its own icon, smaller and lighter than the chevron, with a divider between
them. While it shows, the value ends in an ellipsis before it. On a touch
screen its hit area widens to 44px toward the value, at the field's own
height. Do not pass a size, a colour or your own divider.

`onValueChange` receives an empty value when it is pressed;
`ComboboxField` passes `null` to `onChange`.

## 선택 지우기

"아무것도 고르지 않음"도 올바른 값일 때는 사용자가 필드를 다시 비울 수 있게 합니다.
필터나 필수가 아닌 폼 필드가 그렇습니다. 필수 필드에는 두지 않습니다.

`ComboboxField`에는 이미 들어 있습니다. `SelectField`에는 없으므로, 지울 수 있는
셀렉트는 `Select.*`로 조합합니다. `Select.*`나 `Combobox.*`로 조합할 때는
`ClearTrigger`를 indicator group 안, 화살표 앞에 둡니다.

```tsx
<Select.IndicatorGroup>
  <Select.ClearTrigger aria-label="조직 선택 지우기" />
  <Select.Indicator />
</Select.IndicatorGroup>
```

나머지는 부품이 처리합니다. 무언가 골라져 있을 때만 보입니다. 아이콘을 직접 그리고,
화살표보다 작고 옅게 그리며, 화살표와의 사이에 구분선을 둡니다. 보이는 동안 값은
버튼 앞에서 말줄임으로 끝납니다. 터치 화면에서는 누르는 영역이 값 쪽으로 44px까지
넓어지고, 높이는 필드 높이를 따릅니다. 크기, 색, 구분선을 따로 넘기지 마세요.

누르면 `onValueChange`가 빈 값을 받습니다. `ComboboxField`는 `onChange`에
`null`을 넘깁니다.

## Content

- Label: a noun for what is chosen (답변 언어, 역할), not an instruction (언어를
  선택하세요).
- Placeholder: only when "nothing chosen yet" is a real state. It also becomes
  the hidden name if there is no label, so make it meaningful, but prefer
  `label` or `ariaLabel`.
- Options: short, parallel, sentence case, sorted in a predictable order
  (frequency, size, or alphabetical). Do not repeat the label in each option.
- `emptyText` on `ComboboxField`: say what was not found (일치하는 그룹이
  없습니다).

## Accessibility

What these components do for you:

- **A name, if you give one.** `SelectField` and `ComboboxField` always render
  the label part the trigger points at: visibly for `label`, visually hidden
  for `ariaLabel` (or `placeholder` as a fallback). The name is in the server
  markup, not added after hydration (KWCAG 5.3.4.1 레이블 제공).
- **Keyboard.** The Chakra / Zag listbox handles it: Enter, Space or the arrow
  keys open the list; arrows move; Enter selects; Escape closes and returns
  focus to the trigger. In `ComboboxField` typing filters the list.
- **A name for the clear button.** `ClearTrigger` is named 「선택 지우기」 /
  "Clear selection" in the provider language, instead of Chakra's English
  "Clear value" in every locale. A caller's `aria-label` wins.
- **Focus and states.** The trigger shows a `primary.main` border and ring on
  focus and while open (WCAG 2.4.7). The selected option is bold on
  `primary.selected` and carries a check mark, so it does not rely on colour
  alone (WCAG 1.4.1).

What you still have to do:

- **Always pass `label` or `ariaLabel`.** Inside `FieldRow`, the row's label
  does not reach the trigger: pass the same text as `ariaLabel`. The type does
  not stop you from leaving all three out.
- **Compose `Select.*` / `Combobox.*` with a `Label` part.** Leave it out and
  the trigger has no name. When the label is elsewhere on screen, render
  `<Select.Label srOnly>`.
- Put errors in words (`FieldRow` `error`) as well as `invalid` (WCAG 3.3.1).

## 문구

- 라벨: 고르는 대상을 명사로 씁니다(답변 언어, 역할). "언어를 선택하세요" 같은 지시문은
  쓰지 않습니다.
- 플레이스홀더: "아직 고르지 않음"이 실제로 있는 상태일 때만 씁니다. 라벨이 없으면
  숨은 이름으로도 쓰이므로 뜻이 통하게 쓰되, 되도록 `label`이나 `ariaLabel`을 씁니다.
- 선택지: 짧고 같은 형식으로 쓰며, 자주 쓰는 순, 크기순, 가나다순처럼 예측할 수 있는
  순서로 둡니다. 선택지마다 라벨을 되풀이하지 않습니다.
- `ComboboxField`의 `emptyText`: 무엇을 찾지 못했는지 씁니다(일치하는 그룹이
  없습니다).

## 접근성

이 컴포넌트들이 알아서 하는 일

- **이름을 주면 그대로 씁니다.** `SelectField`와 `ComboboxField`는 트리거가 가리키는
  라벨 부품을 항상 그립니다. `label`이면 보이게, `ariaLabel`(없으면 `placeholder`)이면
  시각적으로 숨겨서 그립니다. 이름은 하이드레이션 뒤에 붙는 것이 아니라 서버가 보낸
  마크업 안에 있습니다(KWCAG 5.3.4.1 레이블 제공).
- **키보드.** Chakra와 Zag의 목록 상자가 처리합니다. Enter, Space, 방향키로 목록을
  열고, 방향키로 옮기고, Enter로 고르며, Escape로 닫으면 초점이 트리거로 돌아갑니다.
  `ComboboxField`에서는 입력하면 목록이 걸러집니다.
- **지우기 버튼의 이름.** `ClearTrigger`는 provider 언어로 「선택 지우기」
  ("Clear selection")라는 이름을 가집니다. Chakra 기본값은 어느 언어에서나 영어
  "Clear value"였습니다. 호출부에서 넘긴 `aria-label`이 우선합니다.
- **초점과 상태.** 트리거는 초점을 받거나 열려 있는 동안 `primary.main` 테두리와 링을
  보여 줍니다(WCAG 2.4.7). 선택된 항목은 `primary.selected` 위에 굵은 글자와 체크
  표시로 나타나므로 색에만 기대지 않습니다(WCAG 1.4.1).

직접 챙겨야 하는 일

- **`label`이나 `ariaLabel`을 반드시 넘깁니다.** `FieldRow` 안에서는 행의 라벨이
  트리거까지 닿지 않으므로 같은 글자를 `ariaLabel`로 넘깁니다. 셋 다 빠뜨려도 타입
  검사에서 걸리지 않습니다.
- **`Select.*`나 `Combobox.*`로 조합할 때는 `Label` 부품을 넣습니다.** 빼면 트리거에
  이름이 없습니다. 라벨이 화면의 다른 곳에 있다면 `<Select.Label srOnly>`를 씁니다.
- 오류는 `invalid`와 함께 `FieldRow`의 `error`로 문구를 보여 줍니다(WCAG 3.3.1).

## Related

- **Radio**: a few options, all visible.
- **Switch** / **Checkbox**: on or off.
- **SegmentedControl** / **Tabs**: switching views.
- **Menu**: actions, not values.
- **FieldRow**: label, helper and error around the field.
- More compositions: the _Multi Select_, _Grouped Options_ and _Custom Items_
