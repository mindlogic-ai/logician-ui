# Pulse

Pops its content once each time `trigger` changes, to draw the eye to a value

# Pulse

<Canvas of={PulseStories.Default} />

<En>

## When to use

- A count or balance that just grew: missions finished, credits added.
- A step indicator that just filled, or a level card when the level changes.
- A badge or chip that just landed, for example at the end of a `FlyTo`.

## When not to use

- The change is a refusal or an error → `Shake`. The pair must stay apart: a
  pulse reads as "good, look here", a shake as "no".
- The element is appearing for the first time → `Appear`. Pulse never plays on
  the first render, so a value that is already set on mount stays still.
- The number itself should be seen changing → `CountUp` (it can sit inside a
  Pulse).
- Values that update continuously (a timer, live progress) → no Pulse. It
  would play on every tick.

## Reduced motion and accessibility

- With `prefers-reduced-motion: reduce` the pop is removed outright. The value
  has already changed by then; only the emphasis is lost.
- Replaying does not remount the children, so keyboard focus and input state
  inside the Pulse are kept.
- The pop is not announced. If the change matters to someone who cannot see
  it, announce the new value yourself (WCAG 4.1.3).
- Pulse adds one `div` (`display: inline-flex`) around `children`. Inside a
  `<button>` pass `as="span"` (ACCESSIBILITY.md §5).

## Props

Any changing value works as `trigger`: a counter, an id, a timestamp. Going
back to an earlier value (`0 → 1 → 0`) still pops.

</En>

<Ko>

## 언제 쓰나요

- 개수나 잔액이 방금 늘었을 때: 완료한 미션 수, 추가된 크레딧.
- 단계 표시가 방금 채워졌거나, 레벨이 바뀌어 레벨 카드가 달라졌을 때.
- 배지나 칩이 방금 도착했을 때. 예를 들어 `FlyTo`가 끝나는 자리입니다.

## 언제 쓰지 않나요

- 거절이나 오류를 알리는 변화라면 `Shake`를 씁니다. 둘은 섞으면 안 됩니다. Pulse는
  "좋아요, 여기 보세요"로, Shake는 "아니요"로 읽힙니다.
- 요소가 처음 나타나는 것이라면 `Appear`를 씁니다. Pulse는 첫 렌더에서 재생되지 않으므로,
  마운트할 때 이미 정해진 값은 움직이지 않습니다.
- 숫자가 바뀌는 과정 자체를 보여 줘야 한다면 `CountUp`을 씁니다(Pulse 안에 넣어도 됩니다).
- 타이머나 실시간 진행률처럼 계속 바뀌는 값에는 Pulse를 쓰지 않습니다. 바뀔 때마다
  튀게 됩니다.

## 동작 줄이기와 접근성

- `prefers-reduced-motion: reduce`에서는 튀는 효과를 아예 뺍니다. 값은 이미 바뀌었으니
  잃는 것은 강조뿐입니다.
- 다시 재생할 때 자식을 새로 마운트하지 않으므로, Pulse 안의 키보드 초점과 입력 상태가
  그대로 유지됩니다.
- 튀는 효과는 읽어 주지 않습니다. 보지 못하는 사람에게도 중요한 변화라면 새 값을 직접
  알립니다(WCAG 4.1.3).
- Pulse는 `children` 바깥에 `div`(`display: inline-flex`)를 하나 더합니다. `<button>`
  안에서는 `as="span"`을 넘깁니다(ACCESSIBILITY.md 5절).

## 속성

`trigger`에는 바뀌는 값이면 무엇이든 넣을 수 있습니다. 카운터, id, 타임스탬프 모두
됩니다. 이전 값으로 돌아가도(`0 → 1 → 0`) 다시 튑니다.

</Ko>
