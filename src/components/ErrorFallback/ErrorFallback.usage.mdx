# ErrorFallback

The full-height card an error boundary renders when a page or a large section
fails to render: what happened, details for support, and a way to try again.

## When to use

- As the `fallback` of a React error boundary or a route-level error page
  (FactChat uses it in its `ErrorBoundary` and route error screens).

## When not to use

- A request failed but the page still works → `Banner` (`danger`) in place, or
  a `Toast`.
- One block inside a page, such as a code block or a table in a chat message,
  failed → a small inline fallback. ErrorFallback is at least one screen tall
  (`100svh`).

# ErrorFallback

페이지나 큰 영역을 그리지 못했을 때 에러 바운더리가 대신 그리는 전체 높이의
카드입니다. 무슨 일이 있었는지, 지원팀에 전할 정보, 다시 시도하는 방법을 보여 줍니다.

## 언제 쓰나요

- React 에러 바운더리의 `fallback`이나 라우트 단위 오류 화면으로 씁니다(FactChat은
  `ErrorBoundary`와 라우트 오류 화면에서 씁니다).

## 언제 쓰지 않나요

- 요청은 실패했지만 페이지는 쓸 수 있다면, 그 자리에 `Banner`(`danger`)를 두거나
  `Toast`를 씁니다.
- 채팅 메시지 안의 코드 블록이나 표처럼 페이지 안의 한 덩어리만 실패했다면 작은 인라인
  대체 화면을 씁니다. ErrorFallback은 높이가 화면 하나(`100svh`) 이상입니다.

<En>

What it shows and does:

- Title, subtitle, help text and button labels come from the library's
  translations, in the app's language.
- `error.message` is shown to the reader as is, in a `danger.bg` box. Throw
  errors whose message a person can read, or pass an `Error` with a
  user-facing message.
- The support block lists the error ID (generated when `errorId` is missing),
  the time, `componentName`, `userId` and the page path.
- **Copy error details** copies a report with the ID, `timestamp`, component,
  message, full URL, user ID and user agent, then confirms with a toast. The
  app must mount `<Toaster />` for that toast to appear.
- **Try again** calls `onErrorReset`; **Refresh page** reloads the window.
- The time on screen is when the card rendered; the `timestamp` prop goes only
  into the copied report.

<Canvas of={ErrorFallbackStories.Default} />

## Accessibility

- The card is a `<section>` named by its title, so it is a landmark even when
  the page's `<main>` failed with it (WCAG 1.3.1).
- The title is an `<h1>` and the support block an `<h2>`, so the outline does
  not skip levels (`ACCESSIBILITY.md` §2, KWCAG 5.2.4.2).
- Move focus to the card's heading when it replaces content the reader was
  using, so a screen reader user learns that the page changed (WCAG 2.4.3).

## Related

- **Banner**: a failure the page survives.
- **Toast**: a failed background action.

- 제목, 부제, 도움말, 버튼 라벨은 라이브러리 번역에서 앱의 언어로 가져옵니다.

## 접근성

- 카드는 제목으로 이름을 붙인 `<section>`이라서, 페이지의 `<main>`이 함께 사라져도
  랜드마크가 남습니다(WCAG 1.3.1).
- 제목은 `<h1>`, 지원 정보는 `<h2>`라서 제목 수준을 건너뛰지 않습니다
  (`ACCESSIBILITY.md` §2, KWCAG 5.2.4.2).
- 사용자가 쓰던 내용을 이 카드가 대신한다면 카드 제목으로 초점을 옮깁니다. 그래야 화면
  낭독기 사용자가 페이지가 바뀐 것을 압니다(WCAG 2.4.3).

## 관련 컴포넌트

- **Banner**: 페이지는 살아 있는 실패.
- **Toast**: 백그라운드 작업의 실패.
