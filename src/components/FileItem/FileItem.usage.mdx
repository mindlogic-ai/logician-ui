# FileItem

One row for one file: its name, upload progress or size, and download and
delete buttons.

## When to use

- A single attached or uploaded file in a form: the CSV just picked, a
  template being uploaded, a verification document.

## When not to use

- Several files → `FileList`, which renders FileItem rows and a "see more".
- A file inside a chat message → the chat attachment components.

# FileItem

파일 하나를 보여 주는 한 줄입니다. 파일 이름, 업로드 진행률이나 크기, 내려받기와 삭제
버튼이 있습니다.

## 언제 쓰나요

- 폼에 붙인 파일 하나: 방금 고른 CSV, 올리는 중인 템플릿, 증빙 서류.

## 언제 쓰지 않나요

- 파일이 여러 개라면 `FileList`를 씁니다. FileItem 행과 "더 보기"를 그려 줍니다.
- 채팅 메시지 안의 파일은 채팅 첨부 컴포넌트를 씁니다.

## 속성

<En>

- `progress` from 0 to 99 shows a percentage, a bar, a spinner and a cancel
  button that calls `onFileDelete`. At 100, or with no `progress`, the row
  shows the size and the actions.
- The download and delete buttons appear only when you pass their handlers.
  `isDownloading` / `isDeleting` swap them for a spinner.
- `error` turns the name, icon and left edge `danger.fg` and puts the message
  in a tooltip on an alert icon. It hides the download button.

## Do / Don't

</En>

<Ko>

- `progress`가 0~99이면 백분율, 진행 막대, 스피너, `onFileDelete`를 부르는 취소 버튼을
  보여 줍니다. 100이거나 `progress`가 없으면 크기와 동작 버튼을 보여 줍니다.
- 내려받기와 삭제 버튼은 처리 함수를 넘겼을 때만 나타납니다. `isDownloading`·
  `isDeleting`이면 버튼 대신 스피너가 보입니다.
- `error`를 주면 이름, 아이콘, 왼쪽 가장자리가 `danger.fg`로 바뀌고, 문구는 경고
  아이콘의 툴팁에 들어갑니다. 내려받기 버튼은 숨겨집니다.

## Content

- Show the real file name; let it truncate rather than rewriting it.
- Error text says what failed and what to do (파일이 5MB를 넘습니다. 나눠서
  올려 주세요.).

## Accessibility

What FileItem does for you:

- Download and delete are `IconButton`s with translated names and tooltips.

Known gaps, and what to do:

- **The error is in a hover tooltip on a non-focusable icon** (WCAG 1.4.1,
  3.3.1). Repeat it in text, as above.
- **The cancel-upload button is named in English** ("remove uploading file
  button") on every screen, Korean included.
- Progress is shown as a percentage and a bar; a screen reader is not told
  when the upload finishes. Announce completion with a toast (WCAG 4.1.3).

## 문구

- 실제 파일 이름을 그대로 보여 줍니다. 길면 고쳐 쓰지 말고 말줄임표로 자릅니다.
- 오류 문구는 무엇이 실패했고 어떻게 하면 되는지 씁니다(파일이 5MB를 넘습니다. 나눠서
  올려 주세요.).

## 접근성

FileItem이 알아서 하는 일

- 내려받기와 삭제는 번역된 이름과 툴팁이 있는 `IconButton`입니다.

알려진 한계와 대처

- **오류 문구가 초점을 받지 않는 아이콘의 툴팁에만 있습니다**(WCAG 1.4.1, 3.3.1). 위처럼
  글자로 한 번 더 보여 줍니다.
- **업로드 취소 버튼 이름이 영어입니다**("remove uploading file button"). 한국어 화면에서도
  영어로 읽힙니다.
- 진행 상황은 백분율과 막대로만 보이고, 업로드가 끝났다는 사실은 화면 낭독기에 알리지
  않습니다. 끝나면 토스트로 알립니다(WCAG 4.1.3).
