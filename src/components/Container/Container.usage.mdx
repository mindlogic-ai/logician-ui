# Container

The centred page column. It is Chakra's `Container` plus a responsive
`minWidth`: the largest theme breakpoint that still leaves a 10% gutter on
each side of the **window**, recomputed on resize. `disableResponsive` turns
that off.

## When to use

- Once per page, around the main content, so pages share the same width.

## When not to use

- Inside a card, a modal, a drawer or a sidebar → `Box` or `Stack` with a
  `maxW`. The width comes from the window, not the parent, so it overflows a
  narrow box.
- To centre a small block → `Flex` / `Center`.

# Container

가운데 정렬된 페이지 열입니다. Chakra의 `Container`에 반응형 `minWidth`를 더했습니다.
**창** 양쪽에 10% 여백을 남기는 가장 큰 테마 중단점 값을 쓰고, 창 크기가 바뀌면 다시
계산합니다. `disableResponsive`로 끌 수 있습니다.

## 언제 쓰나요

- 페이지마다 한 번, 본문을 감싸서 페이지들의 너비를 맞출 때.

## 언제 쓰지 않나요

- 카드, 모달, 서랍, 사이드바 안에서는 `maxW`를 준 `Box`나 `Stack`을 씁니다. 너비가
  부모가 아니라 창에서 정해지므로 좁은 상자 밖으로 넘칩니다.
- 작은 블록을 가운데 두려면 `Flex` / `Center`를 씁니다.

## Accessibility

What Container does for you:

- `as` changes the element and its props, so the page column can be a
  landmark: `as="main"`, `as="section"`, `as="nav"`.

What you still have to do:

- **Mark the main content** with `as="main"` once per page, so "skip to
  content" and landmark navigation work (WCAG 1.3.1, 2.4.1).
- The `minWidth` is set after mount, from the window. Check pages at 320px
  wide and at 400% zoom for sideways scrolling (WCAG 1.4.10).

## Tokens

Container sets no colour tokens.

</En>

<Ko>

## 접근성

Container가 알아서 하는 일

- `as`가 요소와 그 속성을 함께 바꾸므로 페이지 열을 랜드마크로 만들 수 있습니다:
  `as="main"`, `as="section"`, `as="nav"`.

직접 챙겨야 하는 일

- **본문을 표시합니다.** 페이지마다 한 번 `as="main"`을 써야 "본문 바로가기"와
  랜드마크 이동이 동작합니다(WCAG 1.3.1, 2.4.1).
- `minWidth`는 화면에 그려진 뒤 창 크기로 정해집니다. 폭 320px과 400% 확대에서 가로
  스크롤이 생기지 않는지 확인합니다(WCAG 1.4.10).

## 토큰

Container는 색 토큰을 쓰지 않습니다.
