# FileList

A bordered list of `FileItem` rows that shows the first few files and reveals
more on request.

## When to use

- The files attached to something: a chatbot's knowledge files, a project's
  uploads, a policy's documents.

## When not to use

- One file → `FileItem`.
- Hundreds of files the user searches, sorts or selects → `Table`.

- Shows `visibleCount` rows (default 3); the "see more" button adds three at
  a time. With no files it renders nothing.
- A row gets a download button only when the file has a `fileUrl` and you pass
  `onFileDownload`.
- `onFileDelete` may return a promise; the row shows a spinner until it
  settles, and a second click on the same row is ignored meanwhile.

## Content

- When the list is empty, say so outside it (no files yet, and how to add
  one); FileList renders nothing.
- Put a heading or label above it that says whose files these are.

## Accessibility

What FileList does for you:

- Renders a real list (`<ul>` / `<li>`), so a screen reader announces the
  number of files (WCAG 1.3.1).

Known gaps, and what to do:

- **The "see more" button has no focus ring.** Its styles are reset with
  `all: unset`, which removes the outline (WCAG 2.4.7).
- Its count shows the initial `visibleCount`, not the number of rows on
  screen, after the first click.
- Rows inherit the `FileItem` gaps (errors in tooltips, English cancel
  label).

## Tokens

The frame and row dividers are `border.subtle`; the "see more" text and
chevron are `fg.subtle`. Row colours are listed on the FileItem page.

## Related

- **FileItem**: one row.
- **FileInput**: adding files.
- **Table**: large file sets.

## 문구

- 목록이 비면 FileList는 아무것도 그리지 않으므로, 목록 밖에서 아직 파일이 없다는 것과
  추가하는 방법을 알려 줍니다.
- 위에 누구의 파일인지 알려 주는 제목이나 라벨을 둡니다.

## 접근성

FileList가 알아서 하는 일

- 실제 목록(`<ul>`·`<li>`)으로 그리므로 화면 낭독기가 파일 개수를 알려 줍니다(WCAG
  1.3.1).

알려진 한계와 대처

- **"더 보기" 버튼에 초점 표시가 없습니다.** 스타일을 `all: unset`으로 지워서 윤곽선이
  사라집니다(WCAG 2.4.7).
- 한 번 누른 뒤에도 버튼의 숫자는 화면에 보이는 행 수가 아니라 처음 `visibleCount`를
  보여 줍니다.
- 각 행은 `FileItem`의 한계(툴팁 속 오류, 영어 취소 버튼 이름)를 그대로 가집니다.

## 토큰

테두리와 행 구분선은 `border.subtle`, "더 보기" 글자와 화살표는 `fg.subtle`입니다. 행의
색은 FileItem 페이지에 있습니다.

## 관련 컴포넌트

- **FileItem**: 한 줄.
- **FileInput**: 파일 추가.
- **Table**: 많은 파일.
