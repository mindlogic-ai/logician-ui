# SingleDatePicker, RangeDatePicker

A button that opens a calendar for picking one date, or a start and end date.

## When to use

- `RangeDatePicker`: a period to filter by: audit logs, API key usage, group
  usage.
- `SingleDatePicker`: one day, such as an expiry date or a scheduled send.

## When not to use

- A whole month or a range of months → `MonthPicker`.
- A date the user knows by heart and types faster than they click, such as a
  date of birth → `Input` with a clear format.
- A handful of preset periods (last 7 days, last 30 days) → `SegmentedControl`
  or `SelectField`, optionally next to a range picker for "custom".

## Props

Both wrap `chakra-dayzed-datepicker`; its props pass through.
`SingleDatePicker` takes `date` and `onDateChange(date)`; `RangeDatePicker`
takes `selectedDates` and `onDateChange(dates)`. Month and weekday names and
the default `configs.dateFormat` follow the provider language. The trigger is
a `FieldTrigger`, drawn like a `Select` of the same `size`: field height,
padding, type and `border.control` outline, with the calendar ahead of the
date and no chevron. `size` takes the control scale; `2xs` draws as `xs` and
`xl` as `lg`, the nearest field sizes. While nothing is picked it shows
`placeholder` in `fg.placeholder` (default 날짜 선택 / 기간 선택 in the
provider language). Style it with `propsConfigs.triggerBtnProps`, which takes
`FieldTrigger` props (`w`, `bg`, `aria-label`, `size`). The calendar is
portalled (`usePortal` defaults to `true`).

# SingleDatePicker, RangeDatePicker

버튼을 누르면 달력이 열리고, 날짜 하나나 시작일과 종료일을 고릅니다.

## 언제 쓰나요

- `RangeDatePicker`: 감사 로그, API 키 사용량, 그룹 사용량처럼 기간으로 거를 때.
- `SingleDatePicker`: 만료일이나 예약 발송일처럼 하루를 고를 때.

## 언제 쓰지 않나요

- 한 달이나 여러 달의 범위는 `MonthPicker`를 씁니다.
- 생년월일처럼 외우고 있어서 누르는 것보다 입력이 빠른 날짜는 형식을 분명히 적은
  `Input`을 씁니다.
- 최근 7일, 최근 30일 같은 정해진 기간 몇 개는 `SegmentedControl`이나
  `SelectField`를 쓰고, 필요하면 "직접 지정"용으로 기간 선택기를 옆에 둡니다.

## 속성

둘 다 `chakra-dayzed-datepicker`를 감싸며, 그 속성이 그대로 전달됩니다.
`SingleDatePicker`는 `date`와 `onDateChange(date)`를, `RangeDatePicker`는
`selectedDates`와 `onDateChange(dates)`를 받습니다. 월과 요일 이름, 기본
`configs.dateFormat`은 프로바이더의 언어를 따릅니다. 트리거는 `FieldTrigger`라서
같은 `size`의 `Select`와 똑같이 그려집니다. 필드 높이, 여백, 글자 크기,
`border.control` 테두리가 같고, 달력 아이콘은 날짜 앞에 있으며 화살표는 없습니다. `size`는
컨트롤 공통 크기를 받으며 `2xs`는 `xs`로, `xl`은 `lg`로 그립니다. 아무것도 고르지
않았을 때는 `placeholder`를 `fg.placeholder` 색으로 보여 줍니다(기본값은 프로바이더
언어의 날짜 선택 / 기간 선택). 모양은 `propsConfigs.triggerBtnProps`로 바꾸고,
`FieldTrigger` 속성(`w`, `bg`, `aria-label`, `size`)을 받습니다. 달력은 포털로
그려집니다(`usePortal` 기본값 `true`).

## Content

- Label the period (조회 기간, 만료일), not the action (날짜 선택).
- Leave the date format to the default for the language unless the screen
  already uses another one.

## Accessibility

What the pickers do for you:

- The trigger is a real `button`, reachable with Tab, with the popup
  semantics (`aria-haspopup`, `aria-expanded`) from `Popover.Trigger`. Its name
  is the `placeholder` while empty and "placeholder: date" once a date is
  picked, so it is never a bare date or empty.
- The calendar's day buttons and their keyboard behaviour come from
  `chakra-dayzed-datepicker`. Check them with a keyboard on your screen before
  relying on them (WCAG 2.1.1).

What you still have to do:

- **Say what the period is for.** The default placeholder (기간 선택) names
  the action only. Pass a `placeholder` (조회 기간, 만료일), or put the picker in
  `FieldRow` with a label. An `aria-label` through
  `propsConfigs.triggerBtnProps` replaces the whole name, so it must contain
  the visible words (WCAG 2.5.3, 4.1.2; KWCAG 5.3.4.1 레이블 제공).
- Keep an `Input` route for dates far from today; paging month by month to a
  date years away is slow for everyone.

## 문구

- 동작(날짜 선택)이 아니라 기간의 이름(조회 기간, 만료일)을 라벨로 씁니다.
- 화면이 이미 다른 형식을 쓰고 있지 않다면 날짜 형식은 언어별 기본값을 그대로 씁니다.

## 접근성

선택기가 알아서 하는 일

- 트리거는 실제 `button`이라 Tab으로 갈 수 있고, 팝업 정보(`aria-haspopup`,
  `aria-expanded`)는 `Popover.Trigger`가 붙입니다. 이름은 비어 있을 때 `placeholder`,
  날짜를 고른 뒤에는 "placeholder: 날짜"라서 날짜만 있거나 비어 있는 일이 없습니다.
- 달력의 날짜 버튼과 키보드 동작은 `chakra-dayzed-datepicker`가 제공합니다. 화면에
  쓰기 전에 키보드로 직접 확인합니다(WCAG 2.1.1).

직접 챙겨야 하는 일

- **무엇의 기간인지 알려 줍니다.** 기본 placeholder(기간 선택)는 할 일만 말합니다.
  `placeholder`(조회 기간, 만료일)를 주거나 라벨이 있는 `FieldRow`에 넣습니다.
  `propsConfigs.triggerBtnProps`로 준 `aria-label`은 이름 전체를 바꾸므로 화면에
  보이는 글자를 포함해야 합니다(WCAG 2.5.3, 4.1.2, KWCAG 5.3.4.1 레이블 제공).
- 오늘과 멀리 떨어진 날짜는 `Input`으로도 넣을 수 있게 합니다. 몇 년 떨어진 날짜까지 한
  달씩 넘기는 것은 누구에게나 느립니다.
