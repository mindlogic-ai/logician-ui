# LineGraph

A line chart (recharts) for one or more numeric series over an ordered X
axis, usually time: daily questions, usage by model, feedback over a month.
It ships the house grid, axes, tooltip and series colours, in both modes.

## When to use

- A trend over time or another ordered axis, where the shape matters more
  than any single value.

## When not to use

- Comparing categories with no order (models, groups) → a bar chart or a
  `Table`.
- One number → a stat with `Text`. A share of a whole → a `ProgressBar` or a
  table of percentages.
- When the reader needs exact values → a `Table`, with the chart as a
  summary if at all.

## Content

- Name series in words the reader uses (질문 수), not field names (`uv`).
- X labels short: 10/22, not 2026-10-22 00:00.
- Two or three series at most; split into several charts beyond that.

## Accessibility

What LineGraph does for you:

- Axis labels, grid and tooltip read CSS variables, so they follow light and
  dark mode. Default strokes clear 3:1 (WCAG 1.4.11).
- Series names appear as text in the legend and tooltip.

What you still have to do:

- **Give the chart a text alternative** (WCAG 1.1.1). The SVG has no name.
  Put a heading and a one-sentence summary next to it (질문 수는 지난주보다
  12% 늘었습니다), and offer the numbers as a table when they matter.
- **Lines differ only by colour** (no markers, no dash patterns), so with
  three or more series the legend alone can be hard to match (WCAG 1.4.1).
  Keep series few, or label them at the line end.
- The tooltip appears on pointer hover only; keyboard users cannot reach
  values (WCAG 2.1.1). Another reason to offer the table.

## 문구

- 계열 이름은 필드 이름(`uv`)이 아니라 읽는 사람이 쓰는 말(질문 수)로 씁니다.
- X축 라벨은 짧게 씁니다. '2026-10-22 00:00'이 아니라 '10/22'로 씁니다.
- 계열은 많아야 두세 개로 두고, 더 많으면 그래프를 나눕니다.

## 접근성

LineGraph가 알아서 하는 일

- 축 라벨, 격자, 툴팁이 CSS 변수를 읽으므로 라이트·다크 모드를 따릅니다. 기본 선
  색은 3:1 이상입니다(WCAG 1.4.11).
- 계열 이름이 범례와 툴팁에 글자로 나옵니다.

직접 챙겨야 하는 일

- **그래프에 글로 된 대체 내용을 붙입니다**(WCAG 1.1.1). SVG에는 이름이 없습니다.
  옆에 제목과 한 문장 요약('질문 수는 지난주보다 12% 늘었습니다')을 두고, 숫자가
  중요하면 표로도 보여 줍니다.
- **선은 색으로만 구분됩니다**(점 표시나 점선 없음). 계열이 셋 이상이면 범례만으로는
  짝을 맞추기 어렵습니다(WCAG 1.4.1). 계열 수를 줄이거나 선 끝에 이름을 붙입니다.
- 툴팁은 마우스를 올려야만 나타나서 키보드 사용자는 값을 볼 수 없습니다(WCAG
  2.1.1). 이 점에서도 표를 함께 주는 편이 좋습니다.
