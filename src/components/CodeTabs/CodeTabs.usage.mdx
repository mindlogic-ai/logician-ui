# CodeTabs

One example shown in several languages, one tab per language, with an
optional copy button for the tab that is showing. FactChat uses it for the
API access snippet in a chatbot's share settings.

## When to use

- The same call written in two or more languages (cURL, Python,
  JavaScript), where the reader needs only one of them.

## When not to use

- One snippet → `Code`.
- Steps the reader needs in order (install, configure, run) → one `Code`
  block per step, in sequence, so none are hidden.
- Content that is not code → `Tabs`.

## Options

| Prop | Means |
| --- | --- |
| `code` | `{ [language]: source }`. The keys are the tab labels and the highlighting language, in the order given. The first is selected. |
| `onCopy` | Turns the copy button on. The component writes the selected tab's code to the clipboard, then calls `onCopy(code)`. |

The chrome is dark in both colour modes, because the `github-dark` token
colours need a dark ground.

# CodeTabs

하나의 예제를 여러 언어로 보여 주는 컴포넌트입니다. 언어마다 탭이 하나씩 있고, 보이는
탭의 코드를 복사하는 버튼을 켤 수 있습니다. FactChat은 챗봇 공유 설정의 API 접근
예제에 씁니다.

## 언제 쓰나요

- 같은 호출을 두 가지 이상의 언어(cURL, Python, JavaScript)로 보여 주고, 읽는 사람은
  그중 하나만 필요할 때.

## 언제 쓰지 않나요

- 코드가 하나라면 `Code`를 씁니다.
- 순서대로 모두 필요한 단계(설치, 설정, 실행)라면 단계마다 `Code` 블록을 차례로 두어
  숨기는 것이 없게 합니다.
- 코드가 아닌 내용은 `Tabs`를 씁니다.

## 옵션

| 속성 | 뜻 |
| --- | --- |
| `code` | `{ [언어]: 코드 }`. 키가 탭 이름이자 강조 언어이고, 넘긴 순서대로 나옵니다. 첫 탭이 선택됩니다. |
| `onCopy` | 복사 버튼을 켭니다. 선택된 탭의 코드를 컴포넌트가 클립보드에 쓰고 `onCopy(code)`를 부릅니다. |

`github-dark` 색은 어두운 바탕을 전제로 하므로, 두 색 모드 모두에서 어두운 바탕을
씁니다.

## Content

- Use a language identifier Shiki knows as the key (`python`,
  `javascript`, `bash`); it is shown in uppercase, and any other key fails to
  highlight.
- Keep the examples equivalent: same call, same values, same placeholders.

## Accessibility

What CodeTabs does for you:

- The tabs are the house `Tabs`, so the tab pattern (`tablist`, `tab`,
  arrow-key movement) comes with them (WCAG 2.1.1, 4.1.2).
- Hidden panels are `aria-hidden` and invisible, so only the selected
  language is read.
- Text on the dark chrome is at least 7:1 (`action.fg` 70% on `action.bg`)
  in every mode (WCAG 1.4.3).

What you still have to do:

- The copy button's name is the fixed English "Copy"; its tooltip is
  translated. Note it if your screen is Korean-only.
- Say in the text above what the example does (WCAG 1.3.1).

## Tokens

Read from `CODE_CHROME` in `CodeTabs.styles.ts`. It borrows the `action.*`
roles because they are the one pair that stays dark in every mode.

</En>

## 문구

- 키에는 Shiki가 아는 언어 식별자(`python`, `javascript`, `bash`)를 씁니다. 화면에는
  대문자로 나오며, 다른 키를 쓰면 강조가 실패합니다.
- 예제끼리 내용을 맞춥니다. 같은 호출, 같은 값, 같은 바꿔 넣을 자리를 씁니다.

## 접근성

CodeTabs가 알아서 하는 일

- 탭은 이 디자인 시스템의 `Tabs`이므로 탭 패턴(`tablist`, `tab`, 화살표 키 이동)을
  그대로 따릅니다(WCAG 2.1.1, 4.1.2).
- 숨겨진 패널은 `aria-hidden`이고 보이지 않으므로, 선택된 언어만 읽힙니다.
- 어두운 바탕 위의 글자는 모든 모드에서 7:1 이상입니다(`action.bg` 위의 `action.fg`
  70%, WCAG 1.4.3).

직접 챙겨야 하는 일

- 복사 버튼 이름은 영어 "Copy"로 고정되어 있고 툴팁만 번역됩니다. 한국어 전용
  화면이라면 이 점을 기록해 둡니다.
- 예제가 무엇을 하는지 위 본문에서 알립니다(WCAG 1.3.1).

## 토큰

`CodeTabs.styles.ts`의 `CODE_CHROME`에서 읽습니다. 모든 모드에서 어두운 유일한 역할
쌍이라 `action.*`을 빌려 씁니다.
