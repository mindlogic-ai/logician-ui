# PasswordInput

An `Input` for passwords and other secrets, with an eye button that shows or
hides what was typed.

## When to use

- Sign-in, sign-up and password reset.
- A secret the user pastes once, such as an OAuth client secret or an API key.

## When not to use

- A one-time code sent by email or SMS → `PinInput`.
- A secret the user only needs to copy, not type → `CopyableCode`.
- Any value that is not secret → `Input`. Hiding it only makes it harder to
  check.

# PasswordInput

비밀번호 같은 비밀 값을 받는 `Input`입니다. 눈 모양 버튼으로 입력한 내용을 보이거나

## 언제 쓰나요

- 로그인, 회원가입, 비밀번호 재설정.

- 비밀이 아닌 값은 `Input`을 씁니다. 가리면 확인하기만 어려워집니다.

## Content

- Label: "Password", "New password", "Client secret". Korean: 비밀번호, 새
  비밀번호.
- Do not repeat the rule in the placeholder; it disappears on the first
  keystroke.
- Error text names the rule that failed: 8자 이상 입력해 주세요, not
  비밀번호가 올바르지 않습니다.

## Accessibility

What PasswordInput does for you:

- The field itself is the `Input`: native `<input>`, labelled and wired by
  `FieldRow` / `FormControl`.
- The eye button has an accessible name ("Toggle password visibility") and
  does nothing while the field is `disabled`.

What you still have to do, and known gaps:

- **The eye button is mouse and touch only.** It has `tabIndex={-1}` and acts
  on pointer down, so a keyboard user cannot reveal the password (WCAG
  2.1.1). Until the component is fixed, do not make showing the password the
  only way to check it; a confirm field or a clear error works for everyone.
- **Its name is English and its state is not announced.** The label is fixed
  and there is no `aria-pressed`, so a screen reader does not say whether the
  password is shown (WCAG 4.1.2).
- Label the field (WCAG 4.1.2; KWCAG 5.3.4.1 레이블 제공) and put errors in
  `FieldRow` `error` (WCAG 3.3.1).

## Tokens

PasswordInput has no colours of its own. The field reads the `Input` tokens;
the eye button is a ghost `IconButton`.

## Related

- **Input**: the field it wraps, and its tokens.
- **PinInput**: one-time codes.
- **FieldRow**: label, rule and error.

## 문구

- 라벨: 비밀번호, 새 비밀번호, 클라이언트 시크릿.
- 규칙을 플레이스홀더에 되풀이하지 않습니다. 첫 글자를 입력하면 사라집니다.
- 오류 문구는 어긋난 규칙을 말합니다. "비밀번호가 올바르지 않습니다"가 아니라 "8자
  이상 입력해 주세요"라고 씁니다.

## 접근성

PasswordInput이 알아서 하는 일

- 입력란은 `Input` 그대로입니다. 네이티브 `<input>`이고, `FieldRow`나 `FormControl`
  안에서 라벨과 연결됩니다.
- 눈 모양 버튼에는 접근 가능한 이름("Toggle password visibility")이 있고, 입력란이
  `disabled`이면 동작하지 않습니다.

직접 챙겨야 하는 일과 알려진 한계

- **눈 모양 버튼은 마우스와 터치로만 동작합니다.** `tabIndex={-1}`이고 포인터를 누를
  때만 반응하므로 키보드 사용자는 비밀번호를 볼 수 없습니다(WCAG 2.1.1). 컴포넌트가
  고쳐지기 전까지는 비밀번호 보기를 유일한 확인 방법으로 두지 마세요. 확인 입력란이나
  분명한 오류 문구는 누구에게나 통합니다.
- **버튼 이름이 영어이고 상태를 알리지 않습니다.** 라벨이 고정되어 있고
  `aria-pressed`가 없어서, 화면 낭독기는 지금 비밀번호가 보이는지 알려 주지 않습니다
  (WCAG 4.1.2).
- 입력란에 라벨을 붙이고(WCAG 4.1.2, KWCAG 5.3.4.1 레이블 제공), 오류는 `FieldRow`의
  `error`로 보여 줍니다(WCAG 3.3.1).

## 토큰

PasswordInput에는 따로 정한 색이 없습니다. 입력란은 `Input`의 토큰을 쓰고, 눈 모양
버튼은 ghost `IconButton`입니다.

## 관련 컴포넌트

- **Input**: 감싸고 있는 입력란과 그 토큰.
- **PinInput**: 일회용 코드.
- **FieldRow**: 라벨, 규칙, 오류 문구.
