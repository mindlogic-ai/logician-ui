# FlyTo

Sends a ghost of an element arcing from one rect to another, to say "this went
there": a reward chip into a balance, a file into a folder.

# FlyTo

요소의 복제본을 한 위치에서 다른 위치로 포물선을 그리며 날려 보내, "이것이 저기로

<En>

## When to use

- A reward the reader just earned travels to the balance or counter it adds
  to, and the balance updates when it lands (`onDone`).
- An item moves to a place that is visible on screen, and seeing it go there
  explains where it went.

## When not to use

- The target is not on screen, or there is no meaningful source → skip the
  flight and `Pulse` the value that changed.
- Only a number changed → `CountUp`, optionally inside a `Pulse`.
- Something new appears in place → `Appear`.

## Reduced motion and accessibility

- With `prefers-reduced-motion: reduce` nothing flies: FlyTo renders nothing and
  calls `onDone` right after mounting, so whatever the flight was sequencing
  still happens.
- The ghost is decoration. It renders into a portal at the end of the page, so
  a screen reader can reach a copy of its text there. Pass `aria-hidden` when
  the ghost holds text.
- The meaning lives in the state change, not the flight. Update the target
  value in `onDone`, and if the reader must hear it, announce it yourself
  (WCAG 4.1.3).
- The ghost ignores the pointer (`pointer-events: none`), so it never blocks
  a click.

## Props

`from` and `to` are viewport rects, usually from `getBoundingClientRect()`.
The caller mounts FlyTo to start a flight and unmounts it in `onDone`.

</En>

<Ko>

## 언제 쓰나요

- 사용자가 방금 받은 보상이 그것이 더해질 잔액이나 카운터로 날아가고, 도착하는 순간
  잔액이 바뀔 때(`onDone`).
- 항목이 화면에 보이는 다른 자리로 옮겨 가고, 날아가는 모습이 어디로 갔는지를 설명해 줄 때.

## 언제 쓰지 않나요

- 목적지가 화면에 없거나 출발점이 뚜렷하지 않다면 날리지 말고, 바뀐 값에 `Pulse`를
  씁니다.
- 숫자만 바뀌었다면 `CountUp`을 쓰고, 필요하면 `Pulse`로 감쌉니다.
- 새 요소가 제자리에 나타난다면 `Appear`를 씁니다.

## 동작 줄이기와 접근성

- `prefers-reduced-motion: reduce`에서는 아무것도 날지 않습니다. FlyTo는 아무것도
  그리지 않고 마운트 직후 `onDone`을 부르므로, 비행 뒤에 이어지던 일은 그대로 진행됩니다.
- 복제본은 장식입니다. 페이지 끝의 포털에 그려지므로 화면 낭독기가 거기서 그 글자를 한
  번 더 만날 수 있습니다. 복제본에 글자가 있다면 `aria-hidden`을 넘깁니다.
- 뜻은 비행이 아니라 상태 변화에 있습니다. `onDone`에서 목적지 값을 바꾸고, 사용자가
  들어야 하는 변화라면 직접 알립니다(WCAG 4.1.3).
- 복제본은 포인터를 받지 않으므로(`pointer-events: none`) 클릭을 막지 않습니다.

## 속성

`from`과 `to`는 뷰포트 기준 사각형이며 보통 `getBoundingClientRect()`에서 얻습니다.
비행을 시작하려면 FlyTo를 마운트하고, `onDone`에서 언마운트합니다.

</Ko>
