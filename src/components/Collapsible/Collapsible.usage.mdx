# Collapsible

One bordered section with a full-width trigger that shows or hides its
content. `CollapsibleRoot` › `CollapsibleTrigger` + `CollapsibleContent`, or
the same parts as `Collapsible.Root` / `.Trigger` / `.Content` /
`.Indicator`. The height animates on the house presence clock (300 ms in,
150 ms out), and the animation is dropped under reduced motion.

## When to use

- Optional detail the reader rarely needs: raw event data, advanced
  settings, a model's internal process.
- One section. For several sections in a row, use `Accordion`.

## When not to use

- Several sections in a stack → `Accordion`.
- Clipping a paragraph to a few lines → `ExpandableText`.
- Required input or a warning the reader must see → show it on the page.
- A menu of actions → `Menu`.

## Options

| Prop | Means |
| --- | --- |
| `defaultOpen` / `open` + `onOpenChange` | Closed by default; open at start, or controlled |
| `CollapsibleTrigger customIcon` | Replace the default indicator |
| `lazyMount` / `unmountOnExit` | Mount content only when opened |

# Collapsible

테두리가 있는 섹션 하나와, 그 내용을 보이거나 숨기는 전체 너비 트리거로 이뤄진
컴포넌트입니다. 구조는 `CollapsibleRoot` › `CollapsibleTrigger` +
`CollapsibleContent`이고, 같은 파트를 `Collapsible.Root` / `.Trigger` / `.Content` /
`.Indicator`로도 씁니다. 높이는 공통 등장 시간(열 때 300ms, 닫을 때 150ms)으로
움직이고, 움직임 줄이기 설정에서는 애니메이션이 빠집니다.

## 언제 쓰나요

- 읽는 사람이 가끔만 필요한 부가 정보: 이벤트 원본 데이터, 고급 설정, 모델의 내부
  처리 과정.
- 섹션이 하나일 때. 여러 섹션이 이어진다면 `Accordion`을 씁니다.

## 언제 쓰지 않나요

- 섹션 여러 개를 쌓는다면 `Accordion`을 씁니다.
- 문단을 몇 줄만 보여 주려면 `ExpandableText`를 씁니다.
- 필수 입력이나 꼭 봐야 하는 경고는 페이지에 그대로 보여 줍니다.
- 동작 목록이라면 `Menu`를 씁니다.

## 옵션

| 속성 | 뜻 |
| --- | --- |
| `defaultOpen` / `open` + `onOpenChange` | 기본은 닫힘. 처음부터 열어 두거나 제어 값으로 씀 |
| `CollapsibleTrigger`의 `customIcon` | 기본 표시를 바꿈 |
| `lazyMount` / `unmountOnExit` | 열 때만 내용을 그림 |

## Content

- The trigger names what opens: 원본 데이터 보기, 고급 설정.
- Do not change the trigger text when it opens; the indicator and
  `aria-expanded` already say it is open.

## Accessibility

What Collapsible does for you:

- The trigger is a `<button>` with `aria-expanded` and `aria-controls`
  pointing at the content (WCAG 4.1.2). Enter and Space toggle it (WCAG
  2.1.1).
- Under reduced motion the height animation is replaced.

What you still have to do:

- `CollapsibleTrigger` does not add the shared focus ring; it relies on the
  browser's outline. Check that focus is visible where you use it (WCAG
  2.4.7).
- Keep the trigger to phrasing content: text, icons, `Badge`
  (`ACCESSIBILITY.md` §5).
- If the section is part of the page outline, wrap the trigger in a heading
  (WCAG 1.3.1).

## 문구

- 트리거에는 무엇이 열리는지 씁니다: 원본 데이터 보기, 고급 설정.
- 열렸을 때 트리거 문구를 바꾸지 않습니다. 표시 아이콘과 `aria-expanded`가 이미 열린
  상태를 알립니다.

## 접근성

Collapsible이 알아서 하는 일

- 트리거는 `aria-expanded`와 내용을 가리키는 `aria-controls`가 있는 `<button>`입니다
  (WCAG 4.1.2). Enter와 Space로 여닫습니다(WCAG 2.1.1).
- 움직임 줄이기 설정에서는 높이 애니메이션이 다른 효과로 바뀝니다.

직접 챙겨야 하는 일

- `CollapsibleTrigger`는 공통 초점 링을 붙이지 않고 브라우저 기본 외곽선에
  기댑니다. 쓰는 곳에서 초점이 보이는지 확인합니다(WCAG 2.4.7).
- 트리거 안에는 글자, 아이콘, `Badge` 같은 phrasing content만 넣습니다
  (`ACCESSIBILITY.md` 5절).
- 섹션이 페이지 구조의 일부라면 트리거를 제목 요소로 감쌉니다(WCAG 1.3.1).
