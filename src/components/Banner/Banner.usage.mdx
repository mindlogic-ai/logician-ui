# Banner

An inline message that stays on the page, next to the thing it is about, until
the condition behind it changes.

## When to use

- To warn before an action the reader is about to take: an irreversible step,
  something about to expire.
- To state a system fact that shapes what the reader can do here: a setting
  that is locked, a limit, where a value comes from.
- To report a failure that blocks the form or section, with what to do next.

## When not to use

- The message only confirms that something just happened ("Saved") → `Toast`.
- A short status attached to one item → `Badge`.
- An error about one field → the field's own error text (`FormControl`).
- The whole page failed to render → `ErrorFallback`.
- An explanation the reader asks for → `InfoSprinkle` or `Tooltip`.

# Banner

관련된 내용 바로 옆에 붙어서, 원인이 해결될 때까지 화면에 남아 있는 안내
문구입니다.

## 언제 쓰나요

- 되돌릴 수 없는 작업이나 곧 만료되는 항목처럼, 사용자가 하려는 일 앞에서 주의를
  줄 때.
- 잠긴 설정, 한도, 값의 출처처럼 이 화면에서 할 수 있는 일을 정하는 시스템 사실을
  알릴 때.
- 폼이나 영역 전체를 막는 실패를 알리고, 다음에 할 일을 함께 적을 때.

## 언제 쓰지 않나요

- 방금 끝난 일을 확인만 해 준다면("저장했습니다") `Toast`를 씁니다.
- 항목 하나에 붙는 짧은 상태는 `Badge`를 씁니다.
- 입력란 하나의 오류는 그 입력란의 오류 문구(`FormControl`)로 알립니다.
- 페이지 전체를 그리지 못했다면 `ErrorFallback`을 씁니다.
- 사용자가 찾아보는 설명은 `InfoSprinkle`이나 `Tooltip`을 씁니다.

<En>

| Variant | Means | Use for |
| --- | --- | --- |
| `info` (default) | A system fact to know before acting; nothing is wrong | Locked setting, scope, where a value comes from |
| `success` | Finished, and the result stays relevant on this screen | A connection that is now live |
| `warning` | Still works, but read this first | Irreversible step, expiring credit |
| `danger` | Failed or blocked; the reader has to act | Load failure, over a limit, submit error |
| `neutral` | A brand notice with no status | Announcements |

Use `size="sm"` inside cards, dialogs and forms; `md` (default) at the top of a
page section. Banner adds `my={2}`; pass `my={0}` when the parent already sets
the gap.

## Content

- One or two sentences. Lead with what happened or what is true, then what to
  do: "저장하지 못했습니다. 네트워크 연결을 확인한 뒤 다시 시도해 주세요."
- Full sentences end with a full stop. Sentence case in English.
- Numbers and dates the reader needs go in the text, not only in a link.
- Do not repeat the icon's meaning as a prefix ("경고:", "Error:"). The variant
  already says it, and the words say the rest.

## Accessibility

What Banner does for you:

- A string child renders as body text in the variant's `{status}.fg` colour,
  which the contrast audit checks against `{status}.bg` in both modes
  (WCAG 1.4.3).
- The icon is a decoration next to the words; the status is in the text.

What you still have to do:

- **Banner has no live-region role.** A banner that is on the page when it
  loads needs none. One that appears after an action does: pass
  `role="alert"` for an error, `role="status"` for anything else
  (WCAG 4.1.3).
- **Words, not colour alone** (WCAG 1.4.1). If you set `hideIcon`, the text
  still has to say it is a warning or an error when that matters.
- A link or button inside the banner needs a name that makes sense on its own
  (WCAG 2.4.4).

## 문구

- 한두 문장으로 씁니다. 무슨 일이 있었는지 또는 무엇이 사실인지 먼저 쓰고, 다음에 할
  일을 씁니다. 예: "저장하지 못했습니다. 네트워크 연결을 확인한 뒤 다시 시도해 주세요."
- 완전한 문장은 마침표로 끝냅니다. 영어는 문장형 대소문자를 씁니다.
- 사용자에게 필요한 숫자와 날짜는 링크 안에만 두지 말고 본문에 씁니다.
- 아이콘의 뜻을 "경고:", "오류:" 같은 머리말로 반복하지 않습니다. 변형이 이미 알려
  주고, 나머지는 문장이 전합니다.

## 접근성

Banner가 알아서 하는 일

- 문자열을 넘기면 변형의 `{status}.fg` 색으로 본문 글자를 그립니다. 이 색은 대비
  감사에서 라이트·다크 모두 `{status}.bg` 위에서 검사합니다(WCAG 1.4.3).
- 아이콘은 문구 옆의 장식이고, 상태는 문구가 전합니다.

직접 챙겨야 하는 일

- **Banner에는 라이브 영역 역할이 없습니다.** 페이지를 열 때부터 있는 배너는 역할이
  필요 없습니다. 어떤 동작 뒤에 나타나는 배너는 다릅니다. 오류라면 `role="alert"`,
  그 밖에는 `role="status"`를 넘깁니다(WCAG 4.1.3).
- **색만으로 알리지 않습니다**(WCAG 1.4.1). `hideIcon`을 쓴다면, 주의나 오류라는
  사실이 중요할 때 문구가 그것을 말해야 합니다.
- 배너 안의 링크나 버튼에는 그것만 읽어도 뜻이 통하는 이름을 붙입니다(WCAG 2.4.4).
