# Popover

A small panel anchored to the button that opened it, for a few controls or a
short piece of content about that button. The page behind stays usable.

## When to use

- For a few settings that belong to one button: share options, an inline credit
  limit editor, a mail-block toggle.
- For a panel of content opened from the top bar: notifications, announcements,
  the account panel.
- For a picker that needs more than a plain list, such as a model picker with
  a search field.

## When not to use

- A list of actions on one object → `Menu`. Menu gives arrow-key navigation and
  menu roles; a column of buttons in a popover gives neither.
- A short label or hint on hover → `Tooltip`. A definition next to a label →
  `InfoSprinkle`.
- A task the user must finish or cancel before going on → `Modal`.
- On a phone, a list to pick from → `BottomSheet`.

## Variants and what they mean

Popover has no visual variants. `baseFontSize` (default `14px`) sets the base
size that the content's `em` spacing and type scale from.

# Popover

자기를 연 버튼에 붙어 열리는 작은 패널입니다. 그 버튼에 관한 컨트롤 몇 개나 짧은 내용을
담고, 뒤의 페이지는 그대로 쓸 수 있습니다.

## 언제 쓰나요

- 한 버튼에 딸린 설정 몇 가지를 보일 때: 공유 옵션, 바로 고치는 크레딧 한도, 메일 차단
  설정.
- 상단 바에서 여는 내용 패널: 알림, 공지, 계정 패널.
- 단순한 목록보다 많은 것이 필요한 선택기: 검색창이 있는 모델 선택기.

## 언제 쓰지 않나요

- 한 대상에 대한 동작 목록은 `Menu`를 씁니다. Menu는 방향키 이동과 메뉴 역할을
  제공하지만, Popover 안에 버튼을 늘어놓으면 둘 다 없습니다.
- 마우스를 올렸을 때 보이는 짧은 라벨이나 힌트는 `Tooltip`, 라벨 옆의 용어 설명은
  `InfoSprinkle`을 씁니다.
- 끝내거나 취소해야 다음으로 넘어갈 수 있는 작업은 `Modal`을 씁니다.
- 휴대폰에서 목록 중 하나를 고르게 할 때는 `BottomSheet`를 씁니다.

## 변형과 뜻

Popover에는 모양 변형이 없습니다. `baseFontSize`(기본 `14px`)는 콘텐츠의 `em` 단위
간격과 글자 크기가 따르는 기준 크기입니다.

## Content

- **Title:** a noun phrase in sentence case, no full stop: "링크 공유".
- Keep it short enough to read without scrolling. If it needs a scroll bar, it
  probably needs a page or a modal.
- A button inside the panel names its action ("링크 복사"), like any other
  button.

## Accessibility

What Popover does for you:

- The trigger gets `aria-haspopup="dialog"`, `aria-expanded` and
  `aria-controls`; the panel is `role="dialog"`, named by `Popover.Title` and
  described by `Popover.Description` when you render them (WCAG 4.1.2).
- Opening moves focus into the panel; `Escape` closes it and returns focus to
  the trigger (WCAG 2.1.1, 2.4.3). A click outside also closes it.
- It is not modal: focus is not trapped and the page does not lock.

What you still have to do:

- **Render `Popover.Title`** (it may be visually hidden). Without it the dialog
  has no name.
- **Name an icon-only trigger** with `aria-label`.
- Use `Popover.Trigger asChild` on a real `Button`, so the trigger is a single
  button and not a button inside a button.
- Popover content is not portalled. Inside a container with `overflow: hidden`
  it can be clipped; check it there.

## Tokens

The border is set in `PopoverContent` and `PopoverArrowTip`; the panel colour
comes from Chakra's Popover recipe.

</En>

<Ko>

## 문구

- **제목:** 명사구로 쓰고 마침표를 찍지 않습니다. "링크 공유".
- 스크롤 없이 읽을 수 있을 만큼만 담습니다. 스크롤바가 필요하다면 페이지나 모달로 옮길
  때입니다.
- 패널 안의 버튼도 다른 버튼처럼 동작 이름("링크 복사")을 씁니다.

## 접근성

Popover가 알아서 하는 일

- 여는 버튼에 `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls`를 붙입니다.
  패널은 `role="dialog"`이며, `Popover.Title`과 `Popover.Description`을 렌더하면 각각
  이름과 설명이 됩니다(WCAG 4.1.2).
- 열리면 초점이 패널 안으로 옮겨 가고, `Escape`로 닫으면 여는 버튼으로 돌아옵니다
  (WCAG 2.1.1, 2.4.3). 바깥을 눌러도 닫힙니다.
- 모달이 아닙니다. 초점을 가두지 않고 페이지도 잠그지 않습니다.

직접 챙겨야 하는 일

- **`Popover.Title`을 렌더합니다**(눈에 보이지 않게 숨겨도 됩니다). 제목이 없으면
  대화상자에 이름이 없습니다.
- **아이콘만 있는 여는 버튼에는** `aria-label`로 이름을 붙입니다.
- `Popover.Trigger`에 `asChild`를 주고 실제 `Button`을 넣습니다. 그래야 버튼 안에 버튼이
  들어가지 않습니다.
- Popover 콘텐츠는 포털로 빠지지 않습니다. `overflow: hidden`인 컨테이너 안에서는
  잘릴 수 있으니 그 자리에서 확인합니다.

## 토큰

테두리는 `PopoverContent`와 `PopoverArrowTip`에서, 패널 색은 Chakra Popover
레시피에서 정합니다.

## Related

- **Menu**: actions on one object.
- **Tooltip**: a short label on hover or focus.
- **InfoSprinkle**: a definition next to a label.
- **Modal**: a task that stops the page.

</En>

<Ko>

## 관련 컴포넌트

- **Menu**: 한 대상에 대한 동작.
- **Tooltip**: 마우스를 올리거나 초점이 갔을 때 보이는 짧은 라벨.
- **InfoSprinkle**: 라벨 옆의 용어 설명.
- **Modal**: 페이지를 멈추는 작업.
