# Tag

A compact label that classifies an item, or that the reader can select or
remove: a topic, a filter, a chosen group.

## When to use

- To classify items into groups with no fixed meaning: topics, file types,
  departments. Use `category`.
- As a filter chip the reader turns on and off. Render it `as="button"` with
  `selected`.
- To show a choice the reader made and can take back: a selected group in a
  picker, an active filter. Add `TagCloseButton`.

## When not to use

- A status or a well-defined system fact (완료, 실패, 이 그룹만) → `Badge`.
- One choice out of a few, where exactly one is always on → `SegmentedControl`
  or `Tabs`.
- A count → `CountBadge`.
- `Chip` is a deprecated alias of Tag; new code uses Tag.

# Tag

항목을 분류하거나, 사용자가 고르거나 지울 수 있는 작은 라벨입니다. 주제, 필터, 선택한
그룹 같은 곳에 씁니다.

## 언제 쓰나요

- 정해진 뜻이 없는 묶음으로 항목을 나눌 때: 주제, 파일 종류, 부서. `category`를 씁니다.
- 사용자가 켜고 끄는 필터 칩으로 쓸 때. `as="button"`으로 그리고 `selected`를 넘깁니다.
- 사용자가 고른 뒤 다시 뺄 수 있는 선택을 보여 줄 때: 선택기에서 고른 그룹, 적용 중인
  필터. `TagCloseButton`을 붙입니다.

## 언제 쓰지 않나요

- 상태나 뜻이 명확한 시스템 사실(완료, 실패, 이 그룹만)은 `Badge`를 씁니다.
- 몇 가지 중 늘 하나만 켜져 있는 선택은 `SegmentedControl`이나 `Tabs`를 씁니다.
- 개수는 `CountBadge`를 씁니다.
- `Chip`은 Tag의 지원 중단된 별칭입니다. 새 코드에서는 Tag를 씁니다.

## 변형과 뜻

</Ko>

<ArgTypes of={TagStories} include={['tone', 'selected', 'category', 'icon', 'disabled']} />

<En>

| Prop | Means | Use for |
| --- | --- | --- |
| `tone="neutral"` (default) | A plain label | Group names, file extensions, active filters |
| `category` | A group with no meaning beyond telling items apart | Topics, departments, projects |
| `selected` | A filter chip that is on (black fill) | Filter bars |
| `tone="success"` / `warning` / `danger` / `info` | A status every reader shares | Rare on Tag; usually `Badge` is the right component |
| `disabled` | Cannot be used right now | A filter with no results |

When more than one is set, `selected` wins over `category`, and `category`
wins over `tone`.

A tag becomes interactive (pointer, hover border) when it has `onClick`, is a
toggle (`selected` passed, true or false), or renders as a button or a link.
With `as="button"` it gets `type="button"`, `aria-pressed` for a toggle, and the
native `disabled` attribute.

| 속성 | 뜻 | 예 |

| `tone="neutral"` (기본) | 단순한 라벨 | 그룹 이름, 파일 확장자, 적용 중인 필터 |

여러 속성을 함께 주면 `selected`가 `category`보다, `category`가 `tone`보다
우선합니다.

링크로 그리면 Tag는 누를 수 있는 모양(포인터, 호버 테두리)이 됩니다. `as="button"`으로

`disabled` 속성이 붙습니다.

## Content

- One to three words. No full stop.
- Nouns, not verbs: 이미지, not 이미지 보기.
- Sentence case in English. No 「」, quotation marks or brackets around
  Korean labels.
- For a long name, shorten the label and keep the full name in the remove
  button's `aria-label` or a `Tooltip`.

## Accessibility

What Tag does for you:

- A plain tag is a `<span>`, so it is safe inside a button or link (phrasing
  content, `ACCESSIBILITY.md` §5, KWCAG 5.4.1.1).
- `as="button"` adds `type="button"`, `aria-pressed` for a toggle, the native
  `disabled` attribute and the house focus ring (WCAG 2.4.7, 4.1.2).
- A disabled tag that would otherwise be a link or clickable span gets
  `aria-disabled`, leaves the Tab order and ignores clicks.
- Text on every tone and on `selected` passes the contrast audit in both modes
  (WCAG 1.4.3).

What you still have to do:

- **Clickable means a button or a link** (WCAG 2.1.1). `onClick` on the default
  `<span>` is not reachable by keyboard. Use `as="button"`, or `as="a"` with
  `href` when it navigates.
- **Name the remove button.** `TagCloseButton` is an icon-only `<button>` with
  no name and no handler of its own. Pass `aria-label` (for example
  `` `${label} 삭제` ``) and `onClick` (WCAG 4.1.2). Inside a `<form>`, also
  pass `type="button"`, or it submits the form.
- Group related filter chips under a label (`role="group"` with
  `aria-label`, or a visible heading) so a screen reader knows what they
  filter.
- Words, not colour alone (WCAG 1.4.1): category hues only tell items apart;
  the label carries the meaning.

## 문구

- 한 단어에서 세 단어까지 씁니다. 마침표를 찍지 않습니다.
- 동사가 아니라 명사로 씁니다. "이미지 보기"가 아니라 "이미지"라고 씁니다.
- 영어는 문장형 대소문자를 씁니다. 한국어 라벨에는 「」, 따옴표, 괄호를 두르지
  않습니다.
- 이름이 길면 라벨은 줄이고, 전체 이름은 삭제 버튼의 `aria-label`이나 `Tooltip`에
  담습니다.

## 접근성

Tag가 알아서 하는 일

- 기본 Tag는 `<span>`이라 버튼이나 링크 안에 넣어도 됩니다(구문 콘텐츠,
  `ACCESSIBILITY.md` §5, KWCAG 5.4.1.1).
- `as="button"`으로 그리면 `type="button"`, 토글일 때 `aria-pressed`, 기본
  `disabled` 속성, 공통 초점 링이 붙습니다(WCAG 2.4.7, 4.1.2).
- 링크나 누를 수 있는 span이 비활성이면 `aria-disabled`가 붙고, Tab 순서에서 빠지며,
  클릭을 무시합니다.
- 모든 tone과 `selected`의 글자 색은 라이트·다크 모두 대비 감사를 통과합니다(WCAG
  1.4.3).

직접 챙겨야 하는 일

- **누를 수 있다면 버튼이나 링크로 그립니다**(WCAG 2.1.1). 기본 `<span>`에
  `onClick`만 달면 키보드로 닿지 않습니다. `as="button"`을 쓰고, 다른 곳으로
  이동한다면 `href`와 함께 `as="a"`를 씁니다.
- **삭제 버튼에 이름을 붙입니다.** `TagCloseButton`은 아이콘만 있는 `<button>`이며,
  이름도 동작도 스스로 갖지 않습니다. `aria-label`(예: `` `${label} 삭제` ``)과
  `onClick`을 넘깁니다(WCAG 4.1.2). `<form>` 안에서는 `type="button"`도 넘겨야
  폼이 제출되지 않습니다.
- 관련된 필터 칩은 라벨로 묶습니다(`aria-label`을 단 `role="group"`, 또는 눈에 보이는
  제목). 그래야 화면 낭독기 사용자가 무엇을 거르는 필터인지 압니다.
- 색만으로 알리지 않습니다(WCAG 1.4.1). category 색은 항목을 나눌 뿐이고, 뜻은 라벨이
  전합니다.
