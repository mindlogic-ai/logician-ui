# Icon

The icon set: named exports such as `DownloadIcon`, `TrashIcon` and
`CheckIcon`, wrapped from react-icons and custom SVGs with `createIcon`.
Every icon takes `boxSize` (`2xs` 14px, `xs` 16px, `sm` 20px, `md` 24px
default, `lg` 32px, `xl` 40px) and paints `currentColor`, so it takes the
text colour around it unless you pass `color`.

## When to use

- To help recognise an action or item next to its label.
- Inside an `IconButton`, where the button carries the name.

## When not to use

- As the only way to say something (a status, an error) → words, with the
  icon as support (`Badge`, `Banner`).
- As a decorative illustration → an image.
- A new icon from another set inline at the call site → add it to the set
  (see `ICON_MANAGEMENT.md`) so every app gets the same one.

# Icon

아이콘 모음입니다. `DownloadIcon`, `TrashIcon`, `CheckIcon` 같은 이름으로 내보내며,

## 언제 쓰나요

- 라벨 옆에서 동작이나 항목을 알아보기 쉽게 할 때.

- 아이콘만으로 무언가(상태, 오류)를 알리지 않습니다. 문구를 쓰고 아이콘은 거들게
  합니다(`Badge`, `Banner`).
- 장식용 그림에는 이미지를 씁니다.
- 다른 아이콘 모음의 아이콘을 호출부에서 바로 쓰지 않습니다. 모든 앱이 같은 아이콘을
  쓰도록 모음에 추가합니다(`ICON_MANAGEMENT.md` 참고).

## Content

- Use the same icon for the same action everywhere (`TrashIcon` is always
  delete).
- Match the icon size to the text: `xs` beside body text and small buttons,
  `sm`–`md` on their own.

## Accessibility

What Icon does for you:

- It renders an inline SVG in `currentColor`, so it follows the text colour
  in light, dark and high-contrast modes.

What you still have to do:

- **Mark decorative icons `aria-hidden`.** The icon does not hide itself.
- **Name icon-only controls** with `aria-label` on the button (WCAG 4.1.2),
  and keep the label the same as any visible tooltip (WCAG 2.5.3).
- **Icons do not replace words** (WCAG 1.4.1). A standalone icon that means
  something needs at least 3:1 against its background (WCAG 1.4.11);
  `fg.icon` is tuned for that.

## Tokens

The icon paints `currentColor`; these are the roles to set when you pass
`color`.

</En>

<Ko>

## 문구

- 같은 동작에는 어디서나 같은 아이콘을 씁니다(`TrashIcon`은 언제나 삭제).
- 아이콘 크기는 글자에 맞춥니다. 본문과 작은 버튼 옆에는 `xs`, 아이콘만 있을 때는
  `sm`–`md`를 씁니다.

## 접근성

Icon이 알아서 하는 일

- `currentColor`로 칠하는 인라인 SVG라서 라이트, 다크, 고대비 모드에서 글자색을
  따릅니다.

직접 챙겨야 하는 일

- **장식 아이콘에는 `aria-hidden`을 붙입니다.** 아이콘이 스스로 숨지 않습니다.
- **아이콘만 있는 컨트롤에는 버튼에 `aria-label`로 이름을 붙이고**(WCAG 4.1.2), 보이는
  툴팁이 있다면 같은 말을 씁니다(WCAG 2.5.3).
- **아이콘이 문구를 대신하지 않습니다**(WCAG 1.4.1). 뜻을 가진 아이콘이 혼자 있다면
  바탕과 3:1 이상이어야 하며(WCAG 1.4.11), `fg.icon`이 그 기준에 맞춰져 있습니다.

## 토큰

아이콘은 `currentColor`로 칠합니다. 아래는 `color`를 넘길 때 쓰는 역할입니다.
