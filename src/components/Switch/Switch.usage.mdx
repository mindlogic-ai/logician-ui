# Switch

A toggle for one setting that is either on or off.

## When to use

- A single feature or setting the user turns on or off: pin an announcement,
  show it as a pop-up, enable a connector.
- A row in a settings list, with the label on the left and the switch at the
  end.

## When not to use

- Picking items from a list, or several choices that belong together →
  `Checkbox`.
- Agreeing to something → `Checkbox`. "On" is not the same as "I agree".
- One of more than two states → `Radio` or `SelectField`.

# Switch

켜거나 끄는 설정 하나를 바꾸는 토글입니다.

## 언제 쓰나요

- 사용자가 켜거나 끄는 기능이나 설정 하나: 공지 상단 고정, 팝업으로 보여 주기, 커넥터
  사용.
- 설정 목록의 한 행. 라벨은 왼쪽에, 스위치는 행 끝에 둡니다.

## 언제 쓰지 않나요

- 목록에서 항목을 고르거나, 함께 묶이는 여러 선택은 `Checkbox`를 씁니다.
- 동의를 받을 때는 `Checkbox`를 씁니다. "켜짐"은 "동의합니다"와 다릅니다.
- 상태가 셋 이상이라면 `Radio`나 `SelectField`를 씁니다.

<En>

Compose it from `<Switch>`, `<Switch.Control />` and `<Switch.Label>`. The
root is the click target, so the label toggles it too. The thumb settles with
a small overshoot; under reduced motion it moves without it.

If the change is saved the moment the switch flips, say so on the screen (a
toast, or a "saved" line). If it is saved with the rest of the form, keep it
in the form and save on submit, the same as every other field.

## Content

- The label names the setting or feature (상단에 고정), not the action (고정하기)
  and not the state (켜짐).
- One muted line under the label says what changes when it is on.
- No question marks.

## Accessibility

What Switch does for you:

- A native checkbox input carries the state, so Tab focuses it and Space
  toggles it.
- The keyboard focus ring shows on the track (WCAG 2.4.7). The off track is
  `bg.track`, a filled track that stays visible on any surface (WCAG 1.4.11).

What you still have to do:

- **Always render `Switch.Label`** (with `srOnly` if the row's title is
  elsewhere). Without it the switch has no name (WCAG 4.1.2; KWCAG 5.3.4.1
  레이블 제공).
- Position, not colour, shows the state; keep the default thumb so it stays
  that way (WCAG 1.4.1).
- If flipping it saves immediately, announce the result (a toast), so the
  user knows the change was not lost (WCAG 4.1.3).

## 문구

- 라벨에는 설정이나 기능의 이름을 씁니다(상단에 고정). 동작(고정하기)이나 상태(켜짐)는
  쓰지 않습니다.
- 라벨 아래 흐린 글자 한 줄로 켜면 무엇이 달라지는지 씁니다.
- 물음표를 쓰지 않습니다.

## 접근성

Switch가 알아서 하는 일

- 상태는 네이티브 체크박스 입력이 가지고 있어서 Tab으로 초점을 옮기고 Space로 바꿀 수
  있습니다.
- 키보드 초점 링이 트랙에 보입니다(WCAG 2.4.7). 꺼짐 트랙은 어떤 면 위에서도 보이도록
  채워진 `bg.track`을 씁니다(WCAG 1.4.11).

직접 챙겨야 하는 일

- **`Switch.Label`을 항상 그립니다.** 행 제목이 다른 곳에 있다면 `srOnly`를 줍니다.
  라벨이 없으면 스위치에 이름이 없습니다(WCAG 4.1.2, KWCAG 5.3.4.1 레이블 제공).
- 상태는 색이 아니라 손잡이 위치로 드러납니다. 기본 손잡이를 그대로 두어 이 점을
  지킵니다(WCAG 1.4.1).
- 바꾸는 즉시 저장된다면 토스트 등으로 결과를 알려, 바뀐 내용이 사라지지 않았다는 것을
  알 수 있게 합니다(WCAG 4.1.3).
