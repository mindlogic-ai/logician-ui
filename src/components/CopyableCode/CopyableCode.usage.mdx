# CopyableCode

One line of code or a value in a card, with a 복사 button that confirms
itself (the icon becomes a check and the label becomes 복사 완료 for 1.6
seconds). FactChat uses it for model IDs and endpoints on the developer page.

## When to use

- A single value the user copies and pastes elsewhere: an endpoint, a model
  ID, an embed URL.

## When not to use

- Several lines → `Code` with `onCopy`. CopyableCode renders on one line
  (`white-space: nowrap`), so line breaks are lost.
- A value inside a sentence → `InlineCode`.
- A secret shown once (a new API key) → still fine, but say in the text that
  it will not be shown again.

## Props

| Prop | Means |
| --- | --- |
| `children` | The value shown. |
| `onCopy` | **Required, and it does the copying.** CopyableCode does not write to the clipboard; your handler must call `navigator.clipboard.writeText`. The button confirms when clicked either way. |
| `containerProps` | Props for the outer `Flex` (width, margins). |

# CopyableCode

카드 안에 코드 한 줄이나 값을 보여 주고 '복사' 버튼을 붙인 컴포넌트입니다. 버튼을
누르면 1.6초 동안 아이콘이 체크로, 글자가 '복사 완료'로 바뀌어 스스로 확인해 줍니다.
FactChat은 개발자 페이지의 모델 ID와 엔드포인트에 씁니다.

## 언제 쓰나요

- 사용자가 복사해서 다른 곳에 붙여 넣는 값 하나: 엔드포인트, 모델 ID, 임베드 URL.

## 언제 쓰지 않나요

- 여러 줄이라면 `onCopy`를 준 `Code`를 씁니다. CopyableCode는 한 줄로
  그리므로(`white-space: nowrap`) 줄바꿈이 사라집니다.
- 문장 안의 값은 `InlineCode`를 씁니다.
- 한 번만 보여 주는 비밀 값(새 API 키)에도 쓸 수 있지만, 다시 볼 수 없다는 점을 본문에
  적습니다.

## 속성

| 속성 | 뜻 |
| --- | --- |
| `children` | 보여 줄 값. |
| `onCopy` | **필수이며, 복사는 이 함수가 합니다.** CopyableCode는 클립보드에 쓰지 않으므로 넘긴 함수에서 `navigator.clipboard.writeText`를 불러야 합니다. 버튼의 확인 표시는 어느 경우에나 나타납니다. |
| `containerProps` | 바깥 `Flex`에 넘길 속성(너비, 여백). |

## 이렇게 하세요 / 이렇게 하지 마세요

## Content

- Show the exact value, nothing around it: no quotes, no "URL:".
- Put the label in the text above (모델 ID, 엔드포인트).

## Accessibility

What CopyableCode does for you:

- The button is a real `Button` with a visible, translated label, so its name
  matches what is shown (WCAG 2.5.3, 4.1.2).
- Only one label is exposed at a time (the other is `aria-hidden`), and the
  button keeps its width when the label changes.

What you still have to do:

- **Copy for real.** If `onCopy` does nothing, the button still says 복사
  완료 and tells the user something false.
- The confirmation is visual only; there is no live region. If the copy
  result matters (a key shown once), also announce it, for example with a
  `Toast` (WCAG 4.1.3).
- A long value scrolls sideways under a fade. Make sure the start of the
  value is the part that identifies it.

## 문구

- 값만 정확히 보여 줍니다. 따옴표나 "URL:" 같은 말을 붙이지 않습니다.
- 라벨(모델 ID, 엔드포인트)은 위 본문에 씁니다.

## 접근성

CopyableCode가 알아서 하는 일

- 버튼은 번역된 글자가 보이는 실제 `Button`이라, 보이는 글자와 읽히는 이름이
  같습니다(WCAG 2.5.3, 4.1.2).
- 한 번에 한 글자만 노출되고(다른 하나는 `aria-hidden`), 글자가 바뀌어도 버튼 너비가
  그대로입니다.

직접 챙겨야 하는 일

- **실제로 복사합니다.** `onCopy`가 아무것도 하지 않아도 버튼은 '복사 완료'를 띄우므로
  사용자에게 사실이 아닌 것을 알리게 됩니다.
- 확인 표시는 화면에만 나타나고 라이브 영역이 없습니다. 복사 결과가 중요하다면(한 번만
  보여 주는 키 등) `Toast` 같은 방법으로도 알립니다(WCAG 4.1.3).
- 긴 값은 흐려지는 부분 아래로 가로 스크롤됩니다. 값의 앞부분만 보고도 무엇인지 알 수
  있게 합니다.
