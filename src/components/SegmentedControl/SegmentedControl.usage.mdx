# SegmentedControl

A row of two to five mutually exclusive options in one track. Choosing one
changes how the content next to it is shown, or which setting applies.

## When to use

- To change the unit or view of the same data: 일 / 주 / 월, chart / table.
- To filter one list by a small, fixed set: all models, chat models, image
  models.
- For a setting with a few named values that all fit on screen, such as
  상위 설정 따름 / 허용 / 차단.
- To switch the language of a field being edited (한국어 / English).

## When not to use

- To switch between different sections with their own content → `Tabs`.
- For more than five options, or options that do not fit on one line →
  `Select` or `Radio`.
- For on / off → `Switch`.
- For actions (저장, 삭제) → `Button`s. A segment holds a value; it does not
  do something when pressed.
- To pick several at once → `Checkbox` or `Tag` with `selected`.

## Variants and what they mean

SegmentedControl has one look: the selected option sits on a raised thumb in a
`bg.subtle` track. `size` matches the height of the `Button` of the same size,
so a control and a button line up in one row.

</En>

# SegmentedControl

한 트랙 안에 둘에서 다섯 개의 선택지를 나란히 두고 하나만 고르게 합니다. 하나를 고르면
옆 내용을 보는 방식이나 적용되는 설정이 바뀝니다.

## 언제 쓰나요

- 같은 데이터의 단위나 보기를 바꿀 때: 일 / 주 / 월, 차트 / 표.
- 적고 정해진 기준으로 목록 하나를 거를 때: 전체 모델, 대화 모델, 이미지 모델.
- 이름 붙은 값 몇 개가 화면에 다 들어가는 설정: 상위 설정 따름 / 허용 / 차단.
- 편집 중인 입력란의 언어를 바꿀 때(한국어 / English).

## 언제 쓰지 않나요

- 내용이 따로 있는 서로 다른 구역을 오갈 때는 `Tabs`를 씁니다.
- 선택지가 다섯 개보다 많거나 한 줄에 들어가지 않으면 `Select`나 `Radio`를 씁니다.
- 켜고 끄는 것은 `Switch`를 씁니다.
- 저장, 삭제 같은 동작은 `Button`으로 둡니다. 세그먼트는 값을 고르는 것이지 누르면 무언가를
  하는 것이 아닙니다.
- 여러 개를 함께 고르게 하려면 `Checkbox`나 `selected`를 쓰는 `Tag`를 씁니다.

## 변형과 뜻

SegmentedControl의 모양은 하나입니다. `bg.subtle` 트랙 위에 선택된 칸이 떠 있는 판으로
올라옵니다. `size`는 같은 크기의 `Button`과 높이가 같아서 한 줄에 나란히 두면 맞아떨어집니다.

</Ko>

## Content

- One or two words per option, nouns or short adjectives. No full stop.
- Keep options parallel: 일 / 주 / 월, not 일별 / 이번 주 / 월.
- Keep the order fixed across screens. When the same choice appears in several
  places, users find it by position.

## Accessibility

What SegmentedControl does for you:

- It is a radio group: the root is `role="radiogroup"` and each option is a
  radio with a hidden native input, so `Tab` reaches the group and the arrow
  keys change the selection (WCAG 2.1.1, 4.1.2).
- The selected option is shown by the raised thumb and by a heavier, darker
  label, not by colour alone (WCAG 1.4.1). The bold width is reserved in
  advance, so the labels do not shift when the selection moves.
- A hairline ring keeps the track visible on any page colour.

What you still have to do:

- **Name the group.** Pass `aria-label` (or `aria-labelledby` pointing at the
  visible label) on `SegmentedControl`. Without it, a screen reader announces
  the options with no question.
- Give icon-only options a text alternative inside the label.
- A disabled option (`disabled: true` in `options`) cannot be chosen; say why
  nearby if the reason is not obvious.

## Tokens

The table lists the tokens set in `SegmentedControl.tsx`. In dark mode the
ring and the thumb's edge are translucent white, not tokens.

## 문구

- 선택지마다 한두 단어의 명사나 짧은 형용사를 씁니다. 마침표를 찍지 않습니다.
- 선택지를 같은 꼴로 맞춥니다. "일별 / 이번 주 / 월"이 아니라 "일 / 주 / 월"처럼 씁니다.
- 화면이 달라도 순서를 바꾸지 않습니다. 같은 선택이 여러 곳에 나오면 사용자는 위치로
  찾습니다.

## 접근성

SegmentedControl이 알아서 하는 일

- 라디오 묶음입니다. 루트는 `role="radiogroup"`이고 각 선택지는 숨은 기본 입력이 있는
  라디오라서, `Tab`으로 묶음에 닿고 방향키로 선택을 바꿉니다(WCAG 2.1.1, 4.1.2).
- 선택된 칸은 떠 있는 판과 더 굵고 진한 라벨로 보이며, 색만으로 알리지 않습니다
  (WCAG 1.4.1). 굵은 글자의 너비를 미리 잡아 두므로 선택이 옮겨 가도 라벨이 흔들리지
  않습니다.
- 가는 테두리가 있어 어떤 페이지 색 위에서도 트랙이 보입니다.

직접 챙겨야 하는 일

- **묶음에 이름을 붙입니다.** `SegmentedControl`에 `aria-label`을 넘기거나, 보이는
  라벨을 가리키는 `aria-labelledby`를 넘깁니다. 이름이 없으면 화면 낭독기는 무엇을 고르는지
  모른 채 선택지만 읽습니다.
- 아이콘만 있는 선택지에는 라벨 안에 대체 텍스트를 넣습니다.
- 비활성 선택지(`options`의 `disabled: true`)는 고를 수 없습니다. 이유가 분명하지 않다면
  가까이에 이유를 적습니다.
