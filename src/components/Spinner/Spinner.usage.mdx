# Spinner

A small turning ring that says "still working" when the wait is short and its
length is unknown.

## When to use

- Inline, next to the words that say what is loading: a list row, a menu, a
  file being read.
- Inside a custom control that has no loading state of its own.

## When not to use

- A busy button → the button's `loading` prop (Chakra draws the spinner and
  disables the button).
- A whole region or page → `SectionLoader` or `PageLoader`, which also
  announce themselves.
- The AI is working → `ThinkingDots` or the loaders' `thinking` variant.
- Work with a known length → `ProgressBar`.

## How it works

- Chakra's `Spinner` with `color="primary.main"` and the `bg.track` ring.
  `size` takes Chakra's `xs` to `xl`; `color` can be overridden with a token.
- It turns at a constant rate. Under `prefers-reduced-motion` it keeps turning
  at about a third of the speed, because a frozen spinner reads as a hung
  request.

# Spinner

대기가 짧고 얼마나 걸릴지 모를 때 "아직 처리 중"이라고 알려 주는 작은 회전 고리입니다.

## 언제 쓰나요

- 무엇을 불러오는지 알려 주는 글자 옆에 작게 둘 때: 목록 행, 메뉴, 읽는 중인 파일.
- 로딩 상태를 따로 갖지 않은 직접 만든 컨트롤 안에 둘 때.

## 언제 쓰지 않나요

- 작업 중인 버튼은 그 버튼의 `loading` 속성을 씁니다(Chakra가 스피너를 그리고 버튼을
  비활성으로 만듭니다).
- 영역이나 페이지 전체는 `SectionLoader`나 `PageLoader`를 씁니다. 이 둘은 스스로 상태를
  알립니다.
- AI가 일하는 동안에는 `ThinkingDots`나 로더의 `thinking` 변형을 씁니다.
- 길이를 아는 작업은 `ProgressBar`를 씁니다.

## 동작 방식

- `color="primary.main"`과 `bg.track` 고리를 쓴 Chakra `Spinner`입니다. `size`는
  Chakra의 `xs`부터 `xl`까지 받으며, `color`는 토큰으로 바꿀 수 있습니다.
- 일정한 속도로 돕니다. `prefers-reduced-motion`에서는 멈추지 않고 약 3분의 1 속도로
  돕니다. 멈춘 스피너는 요청이 멈춘 것처럼 보이기 때문입니다.

## Accessibility

- **Spinner has no role and no accessible name.** On its own it says nothing
  to a screen reader. Pair it with visible text and wrap both in
  `role="status"` so the change is announced (WCAG 4.1.3, 1.1.1).
- The `bg.track` ring is there so the spinner stays visible on any background
  (WCAG 1.4.11).

## 접근성

- **Spinner에는 역할도 접근 가능한 이름도 없습니다.** 혼자서는 화면 낭독기에 아무것도
  알리지 않습니다. 눈에 보이는 글자와 함께 두고 둘을 `role="status"`로 감싸서 변화가
  읽히게 합니다(WCAG 4.1.3, 1.1.1).
- `bg.track` 고리 덕분에 어떤 배경 위에서도 스피너가 보입니다(WCAG 1.4.11).
